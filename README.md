# Decoded

**The tech everyone's talking about, explained from zero, with code you can run.**

Companion code for the *Decoded* LinkedIn series by [Subhadeep Ghorai](https://www.linkedin.com/in/subhadeep-ghorai). Every week, one trending technology is broken down in 9 slides; this repo holds the tiny working version of it.

## Weeks

| # | Topic | Folder | Status |
|---|---|---|---|
| 01–03 | How LinkedIn decides who sees your post | `01-feed-ranker` | Coming 27 Oct 2026 |
| 04–06 | How AI browser agents click around websites | `02-browser-agent` | Coming 3 Nov 2026 |
| 07–09 | What a sandbox is, and how AI agents escaped one | `03-sandbox` | Coming 10 Nov 2026 |

## Ground rules for every demo

- Plain JavaScript (Node or browser), runs with `npm start` in under a minute
- Under ~100 lines, commented for beginners
- No paid API keys required
- Each folder's README says what is **documented** about the real system and what is **our simplified build**

Fork it, change something, and tag me with what you built.
